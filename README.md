# 🍕 OVO PIZZA — موقع مطعم بيتزا + فاتورة PDF على واتساب

موقع متكامل (Single Page) لمطعم **OVO**:

- لوجو SVG خاص بالمطعم (أوفو + سلايس بيتزا).
- خلفية **فيديو** للفرن الحجري في الهيرو.
- **منيو طويلة** (٩ أقسام / أكتر من ٥٠ صنف) بأحجام وأسعار + بحث + فلترة أقسام.
- سلة طلبات محفوظة في المتصفح (localStorage).
- **فورم طلب كاملة** مع تحقق من كل البيانات: الاسم، الموبايل المصري، رقم احتياطي،
  دليفري ولا استلام من الفرع، المنطقة والعنوان (عمارة/دور/شقة/علامة مميزة)،
  الموعد، طريقة الدفع، ملاحظات، وتأكيد البيانات.
- توليد **فاتورة PDF احترافية** (A4، بالعربي) فيها كل بيانات الأوردر والإجماليات.
- تحميل الفاتورة تلقائيًا + فتح **واتساب المطعم** برسالة فيها تفاصيل الطلب
  (ولو فيه سيرفر PHP، بيترفع الملف ويتبعت لينك مباشر للفاتورة).

## الإعدادات السريعة

كل حاجة في `src/config.ts`:

```ts
whatsapp: "201035215962",   // رقم واتساب المطعم (01035215962) بالصيغة الدولية
phpEndpoint: "/api/order.php",
vatRate: 0.14, minDeliveryOrder: 120,
taxId, commercialReg,       // بيانات الفاتورة الضريبية
AREAS: [...]                // مناطق التوصيل والرسوم
```

### الفاتورة الحقيقية
بعد ملء الفورم بتظهر **معاينة الفاتورة** (A4 حقيقية) فيها: رقم فاتورة متسلسل
`INV-xxxx`، QR Code بيشفّر بيانات الفاتورة، باركود رقم الطلب، الرقم الضريبي
والسجل التجاري، جدول أصناف بأكواد، الإجماليات والضريبة، المبلغ بالحروف،
ختم إلكتروني، وشروط البيع. ومنها بتحمّل PDF أو تبعت على واتساب على طول.

المنيو كلها في `src/data/menu.ts`.

## الباك-إند (PHP)

الملف `public/api/order.php` بيتنسخ مع البناء في `dist/api/order.php`:

1. ارفع محتويات مجلد `dist` على استضافة بتدعم PHP.
2. اعمل مجلد `api/invoices` وخليه قابل للكتابة (chmod 775).
3. السكربت بيستقبل الـ PDF + بيانات الطلب، بيعمل Validation من جهة السيرفر،
   بيحفظ الفاتورة ويسجّل الأوردر في `orders.json`، وبيرجع لينك الفاتورة.
4. جوه الملف كود جاهز (معلّق) لإرسال الفاتورة أوتوماتيك عن طريق
   **WhatsApp Cloud API** أو بالإيميل.

> من غير PHP الموقع بيشتغل عادي: الفاتورة بتتحمّل على جهاز العميل
> وبيتفتح واتساب برسالة كاملة بتفاصيل الأوردر ليرفق الملف.
